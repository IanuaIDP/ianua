These are the sections under **Automation** and **Agents** in a tenant's sidebar: agents and everything inside one, flows, tools and model providers. All of them live in `src/components/dashboard/tenant-detail/sections`.

An **agent** is software that acts for a person. Ann creates an agent that sorts support tickets for her. It proves who it is with a credential. It holds only the access Ann gave it, called a _delegation_. It can be made to wait for a person's approval, and it can be stopped at any time.

`RouteActionsMenu` and `StreamRouteActionsMenu` offer Open to workflows and Close to workflows; a stream route asks for the login in `OpenStreamRouteModal`.

The Save button in `BuilderTopBar` saves at once and creates a new workflow even with no finished step: the API refuses a graph with no step, so such a draft holds one empty step (`EMPTY_DRAFT_KEY`) that is never drawn and is replaced by the first real step. `use-draft-saving.ts` sends complete steps by itself, one edit at a time, with `arrange` apart so moving a card makes no revision. A step not complete stays local, its arrows joined across it on the server, and the copy is kept in `sessionStorage` per workflow (`draft-stash.ts`). `use-draft-stream.ts` reads the draft again on a stream frame and every 15 seconds. `tidy.ts`, `canvas-scene.ts`, `step-issues.ts`, `draft-diff.ts` and `what-it-touches.ts` are pure functions.
