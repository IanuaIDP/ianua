# Security

Ianua is an identity provider, so we take reports seriously.

## Reporting a problem

Please do not open a public issue, discussion or pull request.

Use GitHub's private reporting instead: on this repository, open **Security**,
then **Report a vulnerability**.

Tell us what the problem is, how to reproduce it, and what an attacker could do
with it. Please do not include real user data.

## What to expect

We will confirm that we received your report, tell you what we find, and let you
know when a fix is released. Please give us reasonable time to fix a problem
before you talk about it publicly.

If you report a real vulnerability, we will gladly name you in the security hall
of fame when the fix is released. If you would rather stay anonymous, say so.

## What is in scope

The code in this repository: the platform, the gateway and its companions, the
integrations and the dashboard.

Please do not test against systems you do not own or have permission to test.
