# Code of Conduct

Ianua follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, and keep discussion on the work.
Harassment and personal attacks are not accepted.

To report a problem, use GitHub's private reporting on this repository and say
that it concerns the code of conduct. The maintainers will read it and keep it
confidential.
