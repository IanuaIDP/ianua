This is the first page of the ianua blog. It is a placeholder, and it stays hidden on the live site until a real article replaces it.

## What this blog is for

ianua is an identity provider with a zero-trust gateway built in. The blog is where we plan to write about how that works and why it is built the way it is.

## How articles are added

Each article is one MDX file in `dashboard/content/blog/en/`. The name of the file is the address of the article. A file starts with a short block that gives the title, a one-sentence description, the date, the author and optional tags.

Set `draft: true` in that block to keep an article off the live site while it is being written.
